# QR Studio

黒・オレンジ・白を基調とした、日本語のQRコード作成アプリです。

## できること

- URLからQRコードを作成（https:// の省略可）
- 中央画像の追加・削除（PNG / JPEG / WebP、10MB以内）
- QRコードの色と画像サイズ（256 / 512 / 1024 / 2048px）の選択
- PNG画像の保存、対応端末の共有メニューから送信
- スマートフォン・タブレット・パソコンに対応

入力URLや画像は端末内だけで処理します。外部QR生成API、アクセス解析、ユーザー登録、履歴の保存はありません。通常のWeb配信に伴うアクセスログはホスティングサービス側の扱いに従います。

## 開発

Node.js 22以降を推奨します。

```sh
npm ci
npm run build
npm test
npm run dev
```

開発用URLは `http://127.0.0.1:4173` です。公開には `dist` ディレクトリを静的ホスティングに配信します。サブディレクトリでの配信にも対応します。

`src/` がアプリのJavaScript、`dist/index.html` と `dist/style.css` が画面のソースです。`dist/app.js` はビルド生成物として公開用に含めています。JavaScriptを変更したらビルドし直してください。

## 読み取り・共有の注意

エラー訂正レベルH、4モジュール以上の余白、濃色チェックを使用しています。中央画像を合成した後にjsQRでデコードし、入力URLと一致した場合だけ保存・共有を有効にします。ソフトウェア上での確認はすべてのカメラ・印刷条件での読み取りを保証しません。配布前に実機でもご確認ください。

画像の共有はHTTPSとブラウザーのWeb Share API対応が必要です。共有先アプリは端末により異なります。非対応の場合はPNG保存に切り替わります。iOSでは保存先が「ファイル」になる場合があります。HEIC画像はJPEGなどへ変換してください。

画像は最大2,400万画素、URLは正規化後1,200バイトまで。長いURLは大きい出力サイズが必要になる場合があります。
